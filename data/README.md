### Notes

- All English/Serbian Latin team names are baked into `tools/generate_stickers_json.py`. If you spot a wrong translation, edit the `TEAMS` list there and re-run.
- The script asserts total = 980 and foils = 68 on every run, so a typo that breaks the schema is caught immediately.
- When Panini publishes updates/extras, add them to the script and re-run; do not hand-edit `stickers.json`.
